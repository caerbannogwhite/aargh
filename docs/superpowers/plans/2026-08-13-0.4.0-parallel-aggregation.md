# Parallel Single-Pass Aggregation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace `GroupBy().Agg().Run()`'s two-phase, single-threaded aggregation with a fused, single-pass, parallel hash-aggregation engine, adding Variance/Quantile, fixing Median, and modernizing null/order semantics.

**Architecture:** `GroupBy` becomes lazy (records key columns, builds no partitions); `getPartitions()`/`groupHelper()` materialize on demand so `Join` is untouched. `Agg().Run()` routes to a new engine that, in one parallel pass, hashes each row's group key (interned `*string` pointer for single string keys; exact composite otherwise), updates per-group accumulators (reducible) or collectors (holistic), merges worker state, finalizes, sorts by key, and builds the result.

**Tech Stack:** Go 1.26.5, standard library only (`sync`, `sort`, `runtime`, `math`). Package `dataframe`; series data via `series` package.

## Global Constraints

- Go 1.26.5; pure Go, no cgo, standard library only.
- Result types unchanged: `Count`→`Int64`; `Sum/Mean/Min/Max/Std/Variance/Median/Quantile`→`Float64`.
- Supported input types for value columns: `Bools/Ints/Int64s/Float64s/Durations` (coerced to `float64`); others → error series. Unchanged from today.
- Null-mask convention in series is **bit set = null** (`IsNull(i)`); non-nullable series → `IsNull` always false.
- Strings are interned in the per-`Context` `StringPool`; equal strings share one `*string` (hash by pointer).
- Deliberate behavior changes (approved): result rows **sorted by group key** (nulls last); **null values skipped by default** (`RemoveNAs(false)` restores NaN-poisoning).
- Commit after every green step. Before each commit run `gofmt -l .` (output MUST be empty — run `gofmt -w` on any listed file), `go vet ./dataframe/`, and `go test ./dataframe/ -short`. CI enforces `gofmt` and `golangci-lint`, so non-gofmt code fails the build.

```go
package dataframe

// Interpolation selects how Median/Quantile interpolate between data points
// when the target rank falls between two values (numpy/pandas method set).
type Interpolation uint8

const (
	Linear Interpolation = iota // default: i + (j-i)*frac
	Lower                       // value at the lower rank
	Higher                      // value at the higher rank
	Nearest                     // nearest rank
	Midpoint                    // (i + j) / 2
)

type aggConfig struct {
	ddof      int
	ddofSet   bool
	interp    Interpolation
	interpSet bool
}

// AggOption configures a per-aggregator parameter.
type AggOption func(*aggConfig)

// WithDDoF sets the delta degrees of freedom for Std/Variance (divisor n-ddof).
func WithDDoF(d int) AggOption { return func(c *aggConfig) { c.ddof = d; c.ddofSet = true } }

// WithInterpolation sets the interpolation method for Median/Quantile.
func WithInterpolation(m Interpolation) AggOption {
	return func(c *aggConfig) { c.interp = m; c.interpSet = true }
}

func newAggConfig(opts []AggOption) aggConfig {
	c := aggConfig{ddof: 0, interp: Linear}
	for _, o := range opts {
		o(&c)
	}
	return c
}
```

```go
package dataframe

import "math"

type accumulator interface {
	update(v float64)
	merge(other accumulator)
	result() (float64, bool)
}

type countAcc struct{ n int64 }
func newCountAcc() accumulator { return &countAcc{} }
func (a *countAcc) update(float64)        { a.n++ }
func (a *countAcc) merge(o accumulator)   { a.n += o.(*countAcc).n }
func (a *countAcc) result() (float64, bool) { return float64(a.n), false }

type sumAcc struct{ s float64; n int64 }
func newSumAcc() accumulator { return &sumAcc{} }
func (a *sumAcc) update(v float64)      { a.s += v; a.n++ }
func (a *sumAcc) merge(o accumulator)   { b := o.(*sumAcc); a.s += b.s; a.n += b.n }
func (a *sumAcc) result() (float64, bool) { if a.n == 0 { return 0, true }; return a.s, false }

type meanAcc struct{ s float64; n int64 }
func newMeanAcc() accumulator { return &meanAcc{} }
func (a *meanAcc) update(v float64)    { a.s += v; a.n++ }
func (a *meanAcc) merge(o accumulator) { b := o.(*meanAcc); a.s += b.s; a.n += b.n }
func (a *meanAcc) result() (float64, bool) { if a.n == 0 { return 0, true }; return a.s / float64(a.n), false }

type minAcc struct{ v float64; set bool }
func newMinAcc() accumulator { return &minAcc{} }
func (a *minAcc) update(v float64)    { if !a.set || v < a.v { a.v = v; a.set = true } }
func (a *minAcc) merge(o accumulator) { b := o.(*minAcc); if b.set { a.update(b.v) } }
func (a *minAcc) result() (float64, bool) { return a.v, !a.set }

type maxAcc struct{ v float64; set bool }
func newMaxAcc() accumulator { return &maxAcc{} }
func (a *maxAcc) update(v float64)    { if !a.set || v > a.v { a.v = v; a.set = true } }
func (a *maxAcc) merge(o accumulator) { b := o.(*maxAcc); if b.set { a.update(b.v) } }
func (a *maxAcc) result() (float64, bool) { return a.v, !a.set }

// varAcc: Welford running mean/M2, parallel-mergeable (Chan et al.).
type varAcc struct {
	n    float64
	mean float64
	m2   float64
	ddof int
	std  bool
}
func newVarAcc(ddof int, std bool) accumulator { return &varAcc{ddof: ddof, std: std} }
func (a *varAcc) update(v float64) {
	a.n++
	d := v - a.mean
	a.mean += d / a.n
	a.m2 += d * (v - a.mean)
}
func (a *varAcc) merge(o accumulator) {
	b := o.(*varAcc)
	if b.n == 0 {
		return
	}
	if a.n == 0 {
		a.n, a.mean, a.m2 = b.n, b.mean, b.m2
		return
	}
	delta := b.mean - a.mean
	tot := a.n + b.n
	a.m2 += b.m2 + delta*delta*a.n*b.n/tot
	a.mean += delta * b.n / tot
	a.n = tot
}
func (a *varAcc) result() (float64, bool) {
	denom := a.n - float64(a.ddof)
	if a.n == 0 || denom <= 0 {
		return 0, true
	}
	v := a.m2 / denom
	if a.std {
		return math.Sqrt(v), false
	}
	return v, false
}

func newReducibleAcc(t AggregateType, ddof int) accumulator {
	switch t {
	case AGGREGATE_COUNT:
		return newCountAcc()
	case AGGREGATE_SUM:
		return newSumAcc()
	case AGGREGATE_MEAN:
		return newMeanAcc()
	case AGGREGATE_MIN:
		return newMinAcc()
	case AGGREGATE_MAX:
		return newMaxAcc()
	case AGGREGATE_STD:
		return newVarAcc(ddof, true)
	case AGGREGATE_VARIANCE:
		return newVarAcc(ddof, false)
	}
	panic("newReducibleAcc: not a reducible aggregate")
}
```

```go
package dataframe

import (
	"math"
	"sort"
)

type collector interface {
	collect(v float64)
	merge(other collector)
	result() (float64, bool)
}

// quantileOf computes the p-quantile of a SORTED non-empty slice using the
// given interpolation (numpy/pandas method set). p is clamped to [0,1].
func quantileOf(sorted []float64, p float64, interp Interpolation) float64 {
	n := len(sorted)
	if n == 1 {
		return sorted[0]
	}
	if p <= 0 {
		return sorted[0]
	}
	if p >= 1 {
		return sorted[n-1]
	}
	rank := p * float64(n-1)
	lo := int(math.Floor(rank))
	hi := int(math.Ceil(rank))
	frac := rank - float64(lo)
	switch interp {
	case Lower:
		return sorted[lo]
	case Higher:
		return sorted[hi]
	case Nearest:
		// round half to even
		r := math.RoundToEven(rank)
		return sorted[int(r)]
	case Midpoint:
		return (sorted[lo] + sorted[hi]) / 2
	default: // Linear
		return sorted[lo] + (sorted[hi]-sorted[lo])*frac
	}
}

type quantileCollector struct {
	vals   []float64
	p      float64
	interp Interpolation
}

func newQuantileCollector(p float64, interp Interpolation) collector {
	return &quantileCollector{p: p, interp: interp}
}
func (c *quantileCollector) collect(v float64) { c.vals = append(c.vals, v) }
func (c *quantileCollector) merge(o collector) {
	c.vals = append(c.vals, o.(*quantileCollector).vals...)
}
func (c *quantileCollector) result() (float64, bool) {
	if len(c.vals) == 0 {
		return 0, true
	}
	sort.Float64s(c.vals)
	return quantileOf(c.vals, c.p, c.interp), false
}
```

### Task 4: Group-key table (dense ids, representative values, null keys)

**Files:**
- Create: `dataframe/agg_keys.go`
- Test: `dataframe/agg_keys_test.go`

**Background:** Each row's group key is derived from the group-by columns. Single `Strings` key: use the interned `*string` pointer. Any key column value that is null contributes a sentinel; a row is a "null-key" row only in the sense that its per-column value is null — all rows sharing the same (per-column value-or-null) tuple form one group (this reproduces "nulls group together" and is exact, unlike the current hash mix).

**Interfaces:**
- Consumes: series types from `series` (e.g. `series.Strings.Data_ []*string`, `series.Float64s.Data_`, `IsNull(i)`), `series.Series`.
- Produces:
  - `type groupTable struct { … }` with:
    - `func newGroupTable(keyCols []series.Series) *groupTable`
    - `func (g *groupTable) idOf(row int) int` — returns the dense group id for `row`, assigning a new one (and capturing the row as that group's representative) on first sight.
    - `func (g *groupTable) numGroups() int`
    - `func (g *groupTable) representativeRows() []int` — representative row index per group id (index = gid).
  - The composite key is exact: two rows map to the same id **iff** every key column has an equal value (with null==null per column). - [ ] **Step 3: Write `dataframe/agg_keys.go`**

Implement per-column cell codes + packed composite key. Encode each key column into a `func(row int) uint64` code (dense-coding distinct cell values; null → reserved code 0, real values → 1..k). Pack codes little-endian into a `[]byte` reused per row; the `string([]byte)` is the map key.

```go
package dataframe

import (
	"encoding/binary"

	"github.com/caerbannogwhite/enchanter/series"
)

type groupTable struct {
	coders []func(row int) uint64 // one per key column
	ids    map[string]int
	reps   []int // representative row per gid
	buf    []byte
}

func newGroupTable(keyCols []series.Series) *groupTable {
	g := &groupTable{
		coders: make([]func(int) uint64, len(keyCols)),
		ids:    make(map[string]int, 128),
		buf:    make([]byte, 8*len(keyCols)),
	}
	for i, col := range keyCols {
		g.coders[i] = makeCellCoder(col)
	}
	return g
}

func (g *groupTable) idOf(row int) int {
	for i, code := range g.coders {
		binary.LittleEndian.PutUint64(g.buf[i*8:], code(row))
	}
	key := string(g.buf) // copies bytes; safe map key
	if id, ok := g.ids[key]; ok {
		return id
	}
	id := len(g.reps)
	g.ids[key] = id
	g.reps = append(g.reps, row)
	return id
}

func (g *groupTable) numGroups() int          { return len(g.reps) }
func (g *groupTable) representativeRows() []int { return g.reps }

// makeCellCoder returns a per-row dense code for one key column: 0 == null,
// distinct non-null values get stable codes 1..k. For interned Strings the
// map is keyed by the *string pointer (cheap); other types by their comparable
// value.
func makeCellCoder(col series.Series) func(int) uint64 {
	switch c := col.(type) {
	case series.Strings:
		codes := map[*string]uint64{}
		return func(row int) uint64 {
			if c.IsNull(row) {
				return 0
			}
			p := c.Data_[row]
			if v, ok := codes[p]; ok {
				return v
			}
			v := uint64(len(codes)) + 1
			codes[p] = v
			return v
		}
	default:
		codes := map[any]uint64{}
		return func(row int) uint64 {
			if col.IsNull(row) {
				return 0
			}
			cell := col.Get(row) // comparable boxed value
			if v, ok := codes[cell]; ok {
				return v
			}
			v := uint64(len(codes)) + 1
			codes[cell] = v
			return v
		}
	}
}
```

Note: verify `series.Series` exposes `Get(i int) any` (it is used by `groupHelper`-adjacent code); if the method is named differently (e.g. `GetString`/typed getters), add typed cases for `Ints/Int64s/Float64s/Bools/Times/Durations` in `makeCellCoder` mirroring the `Strings` case (map keyed by the typed value). Prefer typed cases for the numeric/bool/time/duration key types to avoid `any` boxing on the hot path; keep the `default` for anything else.

- Produces:
  - `func aggregateSerial(df BaseDataFrame, keyCols []series.Series, aggs []aggregator, removeNAs bool) DataFrame`
    - Builds one group per distinct composite key; per group holds one accumulator/collector per aggregator.
    - `removeNAs==true` (the new default): null values are skipped. `removeNAs==false`: a null value poisons that group's reducible result to `NaN` (track a per-(group,agg) poisoned flag).

**Design notes for the implementer:**
- Coerce each aggregator's value column once to `[]float64` (`__gdl_stats_preprocess`). `Count` needs no value column.
- One pass over rows: `gid := gt.idOf(row)`; for each aggregator `j`: read `vj := valcols[j][row]`; if `math.IsNaN(vj)` → null (skip if removeNAs else mark poisoned); else `acc[gid][j].update(vj)` / `col[gid][j].collect(vj)`.
- Finalize per gid,agg → `(float64, isNull)`; poisoned reducible → `(NaN,false)`.
- Build key columns using the **same type-switch as `groupHelper` (`base.go:519-572`)** but reading representative rows in **sorted** order; carry the representative row's null flag.
- Emit aggregate columns as `Float64s` (or `Int64s` for `Count`) with a null mask from the finalize `isNull` flags.

```go
type anyAcc struct {
	n   int64
	any bool
}

func newAnyAcc() accumulator { return &anyAcc{} }
func (a *anyAcc) update(v float64) {
	a.n++
	if v != 0 {
		a.any = true
	}
}
func (a *anyAcc) merge(o accumulator) {
	b := o.(*anyAcc)
	a.n += b.n
	if b.any {
		a.any = true
	}
}
func (a *anyAcc) result() (float64, bool) {
	if a.n == 0 {
		return 0, true
	}
	if a.any {
		return 1, false
	}
	return 0, false
}

type allAcc struct {
	n   int64
	all bool // identity: true (AND); only ever cleared
}

func newAllAcc() accumulator { return &allAcc{all: true} }
func (a *allAcc) update(v float64) {
	a.n++
	if v == 0 {
		a.all = false
	}
}
func (a *allAcc) merge(o accumulator) {
	b := o.(*allAcc)
	a.n += b.n
	if !b.all {
		a.all = false
	}
}
func (a *allAcc) result() (float64, bool) {
	if a.n == 0 {
		return 0, true
	}
	if a.all {
		return 1, false
	}
	return 0, false
}
```

### Task 12: Allocation-free group keys (performance)

**Motivation:** Task 10's benchmark measured Q1 @1e7 at **141.8 ms / ~10M allocs/op** vs the spike's **15.5 ms / ~0 per-row allocs** (Polars: 43.2 ms). Root cause: `groupTable.idOf` (`agg_keys.go:44`) does `key := string(g.buf)` — **one heap allocation per row** for the map key. This delivers the interned-`*string`-pointer fast path the spec promised (§2) and should recover most of the spike's win.

**BEHAVIOR-PRESERVING.** The groupTable's external API (`idOf`, `numGroups`, `representativeRows`) and all semantics (null grouping, exact multi-key equality, first-sight representative rows, same group assignment for every input) are UNCHANGED — only the internal key representation changes. `dataframe/agg_engine.go` is NOT modified (it uses only the groupTable API, including the parallel merge's `global.idOf(representativeRow)` re-keying). Every existing test, the parallel parity test, and the poison tests must stay green.

**Files:**
- Modify: `dataframe/agg_keys.go`
- Test: `dataframe/agg_keys_test.go`

**Design** — `newGroupTable(keyCols)` picks a keying strategy once, stored as a `kind`; `idOf(row)` dispatches on `kind` with a predictable branch (NOT a per-row closure/interface call):
- **1 key** — direct keying, no dense-coding, keyed by the raw cell (matches the spike; null rows → a reserved `nullGid`):
  - `series.Strings` → `map[*string]int` keyed by `Data_[row]` (interned pointer).
  - integer-like `Int64s`/`Ints`/`Bools`/`Times`/`Durations` → `map[int64]int` keyed by the raw int64 (Bool→0/1, Time→`UnixNano()`, Duration→`int64(d)`).
  - `Float64s` → `map[uint64]int` keyed by `math.Float64bits(Data_[row])`.
  - any other single type → fall back to the current dense-code + `string(buf)` path.
- **2..8 keys** — dense-code each column (reuse `makeCellCoder`) and pack codes into a fixed-size **array** key `[8]uint64` (slots `0..K-1` = codes, rest 0), `map[[8]uint64]int`. Array keys are comparable and allocation-free.
- **>8 keys** — keep the current `string(buf)` fallback.

**Invariants (unchanged):** null keys → one group (single: `nullGid`; multi: code 0 per null column); exact multi-key equality; representative row = first row that created the group.
